# منصة الشهادات الإلكترونية — جامعة الحضارة العالمية

منصة لإصدار شهادات المدربين والمدربات والمتدربين والمتدربات تلقائياً والتحقق منها، تعمل على GitHub Pages ومربوطة بـ Google Sheets عبر Apps Script.

## محتويات المستودع
| الملف | الوظيفة |
|---|---|
| `index.html` | المنصة: التحقق من الشهادات + لوحة تحكم المشرف العام والمدير التنفيذي |
| `config.js` | رابط تطبيق الويب (Apps Script) — **يجب تعبئته** |
| `apps-script/Code.gs` | الكود الكامل لجدول Google Sheets |
| `apps-script/Verify.html` | صفحة تحقق احتياطية داخل Apps Script |
| `data/*.xlsx` | ملف Excel بكل الأوراق والحقول الجاهزة |
| `fonts/` | ضع هنا خط ثلث مرخّص باسم `thuluth.woff2` (اختياري) |

## خطوات التشغيل
1. افتح جدول Google Sheets ← الإضافات ← Apps Script، والصق `Code.gs`، وأنشئ ملف HTML باسم `Verify` والصق محتواه.
2. من الجدول: قائمة «🎓 نظام الشهادات» ← «تهيئة النظام».
3. نشر ← نشر جديد ← تطبيق ويب (التنفيذ: أنا — الوصول: أي شخص) وانسخ الرابط.
4. ضع الرابط في `config.js` هنا في GitHub.
5. في الجدول ← الإعدادات ← «رابط صفحة التحقق»: ضع رابط هذه الصفحة على GitHub Pages ليفتحها رمز QR.
6. القائمة ← «تفعيل الإصدار التلقائي».

## الدخول
| المستخدم | الرمز الافتراضي | الصلاحيات |
|---|---|---|
| المشرف العام | `123123` | كاملة: إضافة، تعديل، إصدار، إعادة إرسال، إلغاء، تغيير الرموز |
| المدير التنفيذي | `123456` | اطلاع على الإحصاءات والسجلات |

الرموز محفوظة مشفّرة داخل Apps Script وليست في هذه الصفحة. **غيّرها فور التشغيل** من تبويب «الأمان» أو من قائمة الجدول.
